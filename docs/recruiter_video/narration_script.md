### ACT IV — TECHNICAL ARCHITECTURE & STACK (10:15 – 11:30)

#### Visual On-Screen
- Clean architectural diagram:
  - Frontend: Next.js 15 App Router, React 19, TypeScript, Tailwind CSS, Lucide Icons, Recharts, hosted on Vercel Edge.
  - Edge Proxy: Single-origin rewrite routing `/api/v1/*` to backend.
  - Backend: Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0, Uvicorn, hosted on Render.
  - Embedded Data & Solvers: SQLite with Write-Ahead Logging (WAL) for transactional integrity; DuckDB for in-process analytical aggregations; Google OR-Tools with SCIP 9.0 MILP solver; NumPy and Scikit-Learn for forecasting.
  - Memory footprint badge: Process RSS < 50.0 MB.

#### Voiceover Narration
> "Let's look under the hood at the technical architecture.
> 
> SARAS ATLAS is engineered as an in-process modular monolith, prioritizing operational simplicity, zero network serialization latency between services, and strict resource efficiency.
> 
> On the frontend, we utilize **Next.js 15** with the React 19 App Router and **TypeScript**, styled with **Tailwind CSS**. The UI runs on Vercel's Edge Network, where reverse-proxy rewrite rules route all API traffic through a single origin, completely eliminating cross-origin resource sharing overhead and browser preflight latencies.
> 
> On the backend, we run **Python 3.12** and **FastAPI**, with **Pydantic v2** providing strict schema validation. For storage, we use **SQLite in Write-Ahead Logging (WAL) mode** for zero-latency concurrent transactional reads and writes, paired with **DuckDB** for lightning-fast columnar analytical queries on synthetic order logs.
> 
> The optimization core leverages **Google OR-Tools** binding the **SCIP solver**, delivering integer optimal solutions in under 15 milliseconds. Forecasting utilizes **NumPy** and **Scikit-Learn** for regularized regression and smoothing.
> 
> Remarkably, this entire backend—including database, solver, and API layers—operates with a memory footprint of just 50 megabytes of RAM, comfortably under our 350-megabyte budget and running on a strict zero-dollar cloud tier."
