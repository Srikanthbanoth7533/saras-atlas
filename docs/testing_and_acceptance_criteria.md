## 1. Testing Philosophy & Test Pyramid

SARAS ATLAS governs multi-hundred-thousand-dollar business decisions. A mathematical flaw, a broken balance equation, or a floating-point drift can result in false stockout projections or disastrous procurement advice. 

Therefore, testing is organized around a rigorous **Three-Tier Testing Pyramid**:

```
                 / \
                / E2E \       Tier 3: Browser UI Automation (Playwright)
               /-------\      - End-to-end user workflows
              /  Integ  \     Tier 2: API & Integration Tests (Pytest + HTTPX)
             /-----------\    - DB transactions, OR-Tools solver convergence
            /    Unit     \   Tier 1: Deterministic Mathematical Unit Tests
           /---------------\  - Balance equations, GAAP margin waterfall, accounting
```

## 3. Mathematical & Algorithmic Test Suites

### Suite MAT-01: Inventory Conservation & Balance Integrity
- **Test Objective:** Verify that for every day $t$ and SKU $i$, physical inventory satisfies exact conservation:
  $$I_{i}(t) \equiv I_{i}(t-1) + R_i(t) + X_i^{\text{in}}(t) - \text{Fulfilled}_i(t) - X_i^{\text{out}}(t)$$
- **Test Criteria:** No units may appear or vanish spontaneously. Floating-point or integer drift must be **strictly zero** across all 90 simulation days.

### Suite MAT-02: GAAP Unit Contribution Margin Precision
- **Test Objective:** Verify that the Contribution Margin calculation matches the exact GAAP waterfall down to the penny:
  $$\text{CM} = \text{Net Revenue} - (\text{COGS} + \text{InboundFreight} + \text{Tariffs} + \text{PickPack} + \text{Parcel} + \text{Fees} + \text{AdSpend})$$
- **Test Criteria:** Assert absolute delta $| \text{Calculated} - \text{Expected} | < 0.001\text{ dollars}$.

### Suite MAT-03: Mixed-Integer Optimization Global Feasibility
- **Test Objective:** Feed the solver impossible, boundary, and edge-case operational inputs:
  - Budget = $0: Assert solver returns zero air freight without crashing.
  - Delay = 60 days, Budget = $100k: Assert solver selects optimal air freight split satisfying minimum fill rate $\ge 90\%$.
  - Time limit = 3000 ms: Assert solver terminates gracefully and returns best feasible solution if global optimality is not reached.

## 5. Security & Governance Test Suites

### Suite SEC-01: RBAC Permission Enforcement
- Attempt to call `POST /api/v1/governance/approve` using an `Analyst` or `Viewer` role token.
- **Expected Result:** HTTP `403 Forbidden` with structured JSON error payload.

### Suite SEC-02: Two-Man Rule Workflow
- Submit approval from `COO`. Verify recommendation status transitions to `PARTIALLY_APPROVED`.
- Submit second approval from `CFO`. Verify status transitions to `APPROVED` and generates a valid SHA-256 digital signature hash.

### Suite SEC-03: Parameter Boundary Injection
- Submit malicious payloads: `delay_days = -99999`, `surcharge_pct = "DROP TABLE"`, `demand_multiplier = 999999`.
- **Expected Result:** HTTP `422 Unprocessable Entity` generated by Pydantic v2 before domain execution.
